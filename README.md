# 암기카드

모바일 우선 플래시카드 암기 웹앱(PWA)입니다. 로그인 없이 모든 데이터(카드, 이미지·PDF 원본, 학습 기록)를 브라우저 IndexedDB에 저장합니다.

**바로 사용하기: https://kdkcops.github.io/flashcards/**

## 실행

빌드 과정이 없는 정적 파일입니다. 아무 정적 서버로 폴더를 열면 됩니다. Windows에서는 동봉된 스크립트를 쓸 수 있습니다.

```
powershell -ExecutionPolicy Bypass -File serve.ps1
```

브라우저에서 `http://localhost:5173` 을 엽니다. 휴대폰에 설치하려면 HTTPS로 배포해야 합니다(GitHub Pages, Netlify 등에 폴더째 올리면 됨). 그다음 브라우저 메뉴에서 "홈 화면에 추가"를 누르세요.

## 사용법

1. **과목 만들기**: 메인 하단의 **+ 과목**. 과목 화면 상단의 ✏️로 이름을 바꾸고 🗑️로 삭제합니다(삭제 전에 확인 창이 뜹니다).
2. **카드 추가**: 과목 화면에서 **+ 카드 추가**. 앞면과 뒷면 1은 필수, 뒷면 2는 선택입니다.
   - 각 면에 텍스트를 입력하거나 **📎 이미지 / PDF 첨부**로 파일을 붙입니다. 텍스트와 첨부를 함께 쓸 수 있습니다.
   - 파일을 첨부하면 글자를 자동으로 인식해 입력칸에 넣습니다. 인식된 내용은 직접 고칠 수 있습니다.
   - 여러 페이지 PDF는 인식할 페이지를 고르는 창이 뜹니다. 첨부 옆의 **글자 인식** 버튼으로 다시 인식할 수 있습니다.
   - **저장 후 계속**을 누르면 바로 다음 카드를 입력할 수 있습니다.
3. **학습**: 메인의 **오늘 학습** 또는 과목 화면의 **이 과목만 학습**.
   - 카드를 탭하면 뒷면이 나옵니다.
   - **오답**을 누르면 6시간 뒤에 다시 나옵니다.
   - **정답**을 누르면 다음 주기를 고릅니다: 6시간 / 다음날 / 3일 / 일주일 / 한달.
4. **오늘 학습 대상**: 새 카드와, 다음 학습 시각이 지난 카드입니다. 메인에서 주기별 대기 카드 수를 볼 수 있습니다.
5. **백업/복원**: 메인 ⚙️ → 설정. **백업 파일 내보내기**를 누르면 JSON 파일 하나에 첨부 원본까지 모두 담깁니다. **가져오기**를 하면 현재 데이터가 백업 내용으로 교체됩니다.

## 글자 인식(OCR)

- 이미지는 Tesseract.js(한국어+영어)로 인식합니다.
- PDF는 pdf.js로 텍스트를 추출합니다. 텍스트가 없는 스캔본 PDF는 페이지를 이미지로 그린 뒤 OCR합니다.
- 처음 인식할 때 CDN에서 라이브러리와 언어 데이터(약 10–20MB)를 내려받으므로 인터넷 연결이 필요합니다. 이후에는 캐시를 사용합니다.
- 인식에 실패해도 첨부 파일은 남아 있고, 내용을 직접 입력할 수 있습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html`, `styles.css` | 화면 틀, 스타일 (라이트/다크 자동) |
| `app.js` | 화면(메인·과목·카드 편집·학습·설정), 라우팅, 학습 주기 |
| `db.js` | IndexedDB 저장소, 백업/복원 |
| `ocr.js` | Tesseract.js / pdf.js 연동 |
| `sw.js`, `manifest.webmanifest`, `icons/` | PWA(오프라인 캐시, 설치) |
| `serve.ps1` | 로컬 테스트용 서버 |

데이터 모델: `decks`(과목), `cards`(front/back1/back2 = 텍스트 + 첨부 목록, `nextDue`, `lastInterval`), `files`(첨부 원본 Blob), `history`(카드별 학습 일시, 정답 여부, 적용 주기).
